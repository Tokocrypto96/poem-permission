# poem-permission

A short poem about permission — agency: the power to ask and to be given —
written to `/output/entry.txt` by a small, deterministic Python program.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (UTF-8, at most 280 characters) into the directory named
by `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`. No network, standard
library only, same output on every run.
